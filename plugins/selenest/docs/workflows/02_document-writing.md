# 文書作成

読み手と目的を明確にし、必要な情報を選び、読み手が理解・判断・実行できる文書を作成する。
文書の構成には[document-compositionスキル](../../skills/document-composition/SKILL.md)を、文の表現には[writingスキル](../../skills/writing/SKILL.md)を使用する。

## 進め方

### 1. 読み手と目的を明確化する
文書に必要な内容を判断するためには、誰がどのような場面で読み、何ができればよいかを明確にする必要がある。

- 誰が読むのか？
- 読み手は、どの程度の知識や前提を持っているか？
- どのような場面で読むのか？
- 読んだ後に、何を理解・判断・実行できればよいか？

事前に与えられた情報から目的を明確にできず、内容や構成に影響する場合は、ユーザに問いを行う。
仮定を置いて進める場合は、確認済みの条件と区別する。

### 2. 文書の種類と範囲を定める
[document-compositionスキル](../../skills/document-composition/SKILL.md)を使用し、文書の中心となる役割と、この文書で答える問いを明確にする。

関連する文書がある場合は、それぞれが扱う範囲を確認する。
別の文書に任せる内容は、読み手が必要な情報へ進めるように参照先を示す。

目的・読み手・範囲の整理は、内容を選ぶために行う。
整理した内容を、そのまま本文に載せる必要はない。

### 3. 必要な情報を選び、不足を補う
文書の目的を果たすために必要な情報を選ぶ。

- 結論や決定事項は何か？
- 理解や判断に必要な根拠はあるか？
- 前提・適用条件・制約が欠けていないか？
- 事実と推測、提案、未確認事項を区別できているか？

不足がある場合は、追加の調査や確認を行う。
確認できない内容は断定せず、不明点とその影響を示す。

### 4. 構成を決めて書く
[document-compositionスキル](../../skills/document-composition/SKILL.md)に従って、節と段落を組み立てる。
読み手の問いに答える順序を決めてから、本文を書く。

既存の文章を直す場合も、元の項目や構成を残すことを前提にしない。
文の表現には[writingスキル](../../skills/writing/SKILL.md)を適用する。

### 5. 文書全体を見直す
読み手の立場で読み直し、文書の目的を果たしているか確認する。

- 必要な情報が欠けていないか？
- 範囲外の説明や重複が残っていないか？
- 結論と根拠、前提と条件が対応しているか？
- 節と段落の順序を、読み手が無理なく追えるか？
- 参照先に任せすぎず、この文書で必要な判断や行動ができるか？

情報が不足している場合は、[3. 必要な情報を選び、不足を補う](#3-必要な情報を選び不足を補う)に戻る。
情報はそろっていても説明が伝わらない場合は、[4. 構成を決めて書く](#4-構成を決めて書く)に戻る。

構成を修正した後は、[writingスキル](../../skills/writing/SKILL.md)に従って表現を推敲し、前後を続けて読んで意味が通るか確認する。

## 作成を終える基準
以下の事項がそろった場合、文書の作成を終えてよい。

- 想定した読み手が、目的とした理解・判断・実行をできる。
- 必要な根拠・前提・制約が示されている。
- 未確認事項が、確認済みの事実と区別されている。
- 範囲外の説明や、意味のない重複がない。
- 会話の経緯を知らなくても、必要な文脈が分かる。
- 文書全体の構成と、一文ごとの表現を確認している。
- 各記述は、文書の対象を理解・判断・利用するためにあるか。それとも、書き手が何をしたかを説明するためだけにあるか。後者を残す場合は、その説明が文書の目的に必要か確認する。
