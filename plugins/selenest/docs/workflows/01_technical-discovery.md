# 技術調査

実現したいことに対して候補を調べ、比較して実現方式を選ぶ。
候補の広げ方、根拠の扱い、比較・選定の判断基準には、[technical-discoveryスキル](../../skills/technical-discovery/SKILL.md)を使用する。

## 進め方

### 1. 目的と条件を明確化する

実現したいこと、必須条件、優先事項、調査の範囲を整理する。
既存製品上の導入・共有・更新の方式を選ぶ場合は、更新の頻度と、設定やバージョンを共有する範囲を整理する。選定を左右する条件が不明な場合は、仮定または確認が必要な事項として示す。
選択の基準を置けたら、概要の調査へ進む。仮定を置いた条件は、確認済みの条件と区別して引き継ぐ。

### 2. 概要を理解する

キーワードを起点に、基本概念や仕組み、関連技術を調べる。
既存製品上の導入・共有・更新を扱う場合は、目的に関係する標準機構を調べ、導入・更新・適用範囲の管理をどこまで担えるか確認する。
候補を探す対象と次に確かめる問いを説明できたら、実現方式の調査へ進む。

### 3. 実現方式の候補を広げる

目的を達成できそうな技術、構成、設計を探し、各候補の成立条件や制約を調べる。
既存製品上の導入・共有・更新を扱う場合は、各候補について、標準機構で満たせる条件と、追加の実装・運用が必要な条件を整理する。選定に影響する未確認事項は、比較の段階へ引き継ぐ。
比較する有力な候補が見えてきたら、共通の観点で整理する。

### 4. 比較して不足を調べなおす

目的と条件に沿って候補を比較し、選択に必要な根拠の不足を確認する。
不足があれば、次に確認する問いを定めて[候補の調査](#3-実現方式の候補を広げる)へ戻る。必要に応じて検証や試作を行う。
目的や条件の見直しが必要と分かった場合は、[目的と条件の整理](#1-目的と条件を明確化する)へ戻る。

### 5. 候補を絞り込んで選択する

スキルの[調査を区切る基準](../../skills/technical-discovery/SKILL.md#調査を区切る基準)に照らして、選定へ進めるか判断する。
選定へ進む場合は、採用案とその根拠、受け入れる条件、残る不明点をまとめる。
基準を満たせない場合は、検証、条件の見直し、判断の保留のいずれかに進み、次に行うことを示して区切る。
